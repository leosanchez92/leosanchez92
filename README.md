# ¡Hola! 👋 Soy Nelson (leosanchez92)

> 📜 **Nota arqueológica**
>
> Este perfil fue construido hace varios años, cuando la asistencia para programar era buscar soluciones en foros de StackOverflow a las 2 a.m., y reparar el código a prueba y error. Cada proyecto acá fue pensado, escrito y depurado a mano. Hecho con cariño y pocas horas de sueño.

Trabajo en visualización geográfica y territorial: visores interactivos con [Leaflet](https://leafletjs.com/) para mostrar datos de viñedos, planificación urbana, áreas verdes, salud y organización comunitaria.

## 🗺️ Proyectos destacados

- **[Web_vinos](https://github.com/leosanchez92/Web_vinos)** — Mapa interactivo de viñedos "Guía Kalycatas".
- **[VISOR_V1](https://github.com/leosanchez92/VISOR_V1)** — Visor territorial de Nueva Imperial (JJVV, PRC, Áreas Verdes, Salud).
- **[VISOR_V1_NACIMIENTO](https://github.com/leosanchez92/VISOR_V1_NACIMIENTO)** — Visor territorial de Nacimiento (PRC).

## 🛠️ Stack
